# ESP32 Security System

Умная охранная система на базе ESP32 с интеграцией Telegram Bot через Java Spring Boot.

## Структура проекта
Проект разделен на две основные части:
- `firmware/` — Прошивка для микроконтроллера ESP32 (написана на C с использованием фреймворка ESP-IDF).
- `backend/` — Серверная часть (написана на Java 21, фреймворк Spring Boot). Отвечает за связь с платой по COM-порту и управление через Telegram-бота.

## Функционал
- **Датчик движения (PIR)** и **Ультразвуковой дальномер**.
- **Оповещения в Telegram**: мгновенные уведомления о нарушении периметра или резких вспышках света.
- **Динамическое управление**: включение/выключение охраны (`ARM`/`DISARM`) прямо из Telegram.
- **Динамические пороги**: изменение чувствительности датчиков света и дистанции "на лету" без перепрошивки.
- **Режим Сирены ("Полиция")**: попеременное мигание красным и зеленым светодиодами и двухтональный сигнал зуммера для отпугивания злоумышленников.

## Инструкция по запуску

### 1. Прошивка ESP32
1. Откройте папку `firmware/` в VS Code с установленным расширением ESP-IDF.
2. Выберите ваш COM-порт в настройках ESP-IDF (нижняя панель).
3. Нажмите кнопку `Build, Flash and Monitor`. 
   *(Обязательно закройте Monitor в VS Code перед запуском Java-приложения, чтобы освободить COM-порт!)*

### 2. Запуск Backend (Spring Boot)
1. Откройте папку `backend/` в вашей IDE (IntelliJ IDEA или VS Code).
2. Создайте файл `.env` в папке `backend/` со следующим содержимым:
   ```env
   TELEGRAM_BOT_USERNAME=ваше_имя_бота
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   SERIAL_PORT=COM4 # или /dev/ttyUSB0 для Linux/Mac
   ```
3. Запустите приложение (`SecurityApp.java` или через Maven: `mvn spring-boot:run`).
4. Напишите `/start` вашему боту в Telegram и используйте меню с кнопками для управления системой!
